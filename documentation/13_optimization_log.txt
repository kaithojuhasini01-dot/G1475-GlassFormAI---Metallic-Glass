# NSGA-II Composition Optimization Log

**Date:** 08-11-2026

## 1. Implementation & Execution
We successfully implemented and executed the NSGA-II genetic algorithm to optimize the Zr-Cu-Ni-Al composition for maximum Glass-Forming Ability (GFA). 

**Operating System Challenge:** We initially attempted to run the script locally in VS Code on a Windows OS. However, we encountered a known Windows multiprocessing `RuntimeError` when `pymoo` tried to run parallel processes with `pymatgen` and `matminer`. 

**Resolution:** To overcome this, we executed the exact same script on **Google Colab (Linux environment)**, which handles multiprocessing natively and successfully bypassed the Windows limitation.

## 2. Parameters & Computational Limits
The base paper utilized an Initial Population of 200 and 300 Generations. However, evaluating the `pymatgen` and `matminer` features for 60,000 compositions is computationally expensive on a standard Google Colab CPU (taking over 10 hours). 

To demonstrate the algorithm's functionality within our time constraints, we ran the optimization with:
- **Population Size:** 50
- **Generations:** 20
- **Search Space:** Cu (5-20%), Ni (5-20%), Al (5-10%), Zr (balance).

Even with these reduced parameters, the genetic algorithm successfully converged to a highly optimized Pareto front.
